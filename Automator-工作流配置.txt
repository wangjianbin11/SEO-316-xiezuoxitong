# SEO 内容生成器 - Automator 工作流配置

## 使用方法

### 方法 1：手动创建（推荐）

1. 打开 **Automator**（在"应用程序"文件夹或通过 Spotlight 搜索）
2. 选择 **"应用程序"** 作为文档类型
3. 点击 **"选取"**

4. 在左侧搜索栏搜索 **"运行 Shell 脚本"**
5. 将 **"运行 Shell 脚本"** 拖到右侧工作区

6. 将下面的脚本粘贴到脚本框中：

```bash
#!/bin/bash

# ==================================================
# SEO 内容生成器 - Mac 应用启动脚本
# ==================================================

# 获取应用程序所在目录的父目录（项目根目录）
# Automator 应用结构: SEO内容生成器.app/Contents/MacOS/脚本文件
# 需要回到项目根目录

SCRIPT_PATH="$0"
APP_DIR="$(dirname "$(dirname "$(dirname "$SCRIPT_PATH")")")"

# 检查应用是否在 .app 包内，如果是则向上查找项目目录
if [[ "$APP_DIR" == *.app ]]; then
    # 应用在包内，需要找到项目根目录
    # 假设应用和项目在同一目录
    APP_DIR="$(dirname "$APP_DIR")"
fi

# 切换到项目目录
cd "$APP_DIR"

# 设置 Python 路径（确保能找到 python3）
export PATH="/usr/local/bin:/usr/bin:/bin:/opt/homebrew/bin:$PATH"

# 设置 PYTHONPATH
export PYTHONPATH="$APP_DIR/src:$PYTHONPATH"

# 加载 .env 文件（如果存在）
if [ -f "$APP_DIR/.env" ]; then
    export $(cat "$APP_DIR/.env" | grep -v '^#' | xargs)
fi

# 检查并激活虚拟环境
if [ -d "$APP_DIR/venv" ]; then
    source "$APP_DIR/venv/bin/activate"
fi

# 检查 Python
if ! command -v python3 &> /dev/null; then
    osascript -e 'display dialog "未找到 Python 3。请先安装 Python 3。" buttons {"OK"} with icon stop'
    exit 1
fi

# 检查依赖
if ! python3 -c "import customtkinter" 2>/dev/null; then
    osascript -e 'display dialog "缺少依赖包。正在尝试安装..." buttons {"OK"} with icon note'
    pip3 install -e "$APP_DIR" --quiet
fi

# 启动 GUI
python3 -m seo_gen.gui

# 如果程序异常退出，显示提示
if [ $? -ne 0 ]; then
    osascript -e 'display dialog "程序启动失败或异常退出。请检查配置和依赖。" buttons {"OK"} with icon stop'
fi
```

7. **保存应用程序**
   - 按 `Cmd + S`
   - 选择 **"应用程序"** 作为文件格式
   - 命名为 **"SEO 内容生成器"**
   - 保存到 **"应用程序"** 文件夹或桌面

8. **设置图标（可选）**
   - 准备一个图标文件（.icns 格式）
   - 右键点击创建的应用 → **"显示简介"**
   - 将图标文件拖到左上角的图标上

### 方法 2：使用 Platypus（更简单）

1. 下载并安装 [Platypus](https://sveinbjorn.org/platypus)

2. 打开 Platypus，配置如下：
   - **App Name**: SEO 内容生成器
   - **Script Type**: Shell
   - **Script**:
   ```bash
   #!/bin/bash
   cd "$APP_PATH"
   export PYTHONPATH="$APP_PATH/src:$PYTHONPATH"
   python3 -m seo_gen.gui
   ```

3. **Options** 选项卡：
   - ✅ Is background app（后台应用）
   - ✅ Remain running after execution
   - ✅ Send output to log file

4. 点击 **"Create"** 创建应用程序

## 修改应用图标

### 准备图标文件

1. 准备一个 PNG 图片（建议 1024x1024）
2. 使用在线工具转换为 .icns：
   - https://cloudconvert.com/png-to-icns
   - 或使用 Terminal：
   ```bash
   # 创建图标集
   mkdir icon.iconset
   sips -z 16 16     icon.png --out icon.iconset/icon_16x16.png
   sips -z 32 32     icon.png --out icon.iconset/icon_16x16@2x.png
   sips -z 32 32     icon.png --out icon.iconset/icon_32x32.png
   sips -z 64 64     icon.png --out icon.iconset/icon_32x32@2x.png
   sips -z 128 128   icon.png --out icon.iconset/icon_128x128.png
   sips -z 256 256   icon.png --out icon.iconset/icon_128x128@2x.png
   sips -z 256 256   icon.png --out icon.iconset/icon_256x256.png
   sips -z 512 512   icon.png --out icon.iconset/icon_256x256@2x.png
   sips -z 512 512   icon.png --out icon.iconset/icon_512x512.png
   sips -z 1024 1024 icon.png --out icon.iconset/icon_512x512@2x.png

   # 生成 .icns 文件
   iconutil -c icns icon.iconset
   ```

### 应用图标

1. 右键点击应用 → **"显示简介"**
2. 将 .icns 文件拖到左上角的图标上
3. 图标会立即更新

## 添加到 Dock

1. 创建应用后，从"应用程序"文件夹拖到 Dock
2. 右键 Dock 中的图标 → **"选项"** → **"在 Dock 中保留"**

## 开机自动启动

1. 打开 **"系统偏好设置"**
2. 点击 **"用户与群组"**
3. 选择您的用户 → **"登录项"** 选项卡
4. 点击 **"+"** 按钮
5. 选择创建的 **"SEO 内容生成器"** 应用

## 故障排除

### 应用无法启动

1. 打开 **"控制台"** 应用（在"实用工具"文件夹）
2. 搜索 **"SEO 内容生成器"**
3. 查看错误日志

### 手动测试

在终端中运行以下命令测试：
```bash
cd /path/to/seo-content-generator
export PYTHONPATH="$PWD/src:$PYTHONPATH"
python3 -m seo_gen.gui
```

### 重新创建应用

如果应用出现问题，删除后重新创建：
1. 删除旧的应用
2. 按照"方法 1"或"方法 2"重新创建
