# 网址抓取功能说明

## 功能概述

支持三种方式抓取网址内容，按优先级自动尝试：

### 1. Playwright 浏览器模拟（首选）✅
**特点**：
- 真实浏览器环境，支持 JavaScript 渲染
- 自动等待页面加载完成
- 支持动态内容（SPA、React、Vue 等）
- 使用指定 User-Agent 模拟真实用户

**User-Agent**:
```
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/144.0.0.0 Safari/537.36
```

**启动参数**：
```python
--disable-blink-features=AutomationControlled  # 禁用自动化检测特征
--disable-dev-shm-usage                          # 共享内存优化
--no-sandbox                                     # 非沙箱模式
```

**等待策略**：
- `networkidle` - 等待网络空闲
- 额外 2 秒等待动态内容加载
- 总超时 30 秒

**内容提取优先级**：
1. 查找主要内容区域（article、main、.post-content 等）
2. 提取所有段落 `<p>`
3. 获取整个 body

### 2. Web-Reader MCP 工具（备用）
- 预留接口，可集成 MCP web-reader 工具
- 需要特定上下文环境

### 3. Requests + BeautifulSoup（后备）
- 纯 HTTP 请求
- HTML 解析
- 使用相同 User-Agent
- 超时 15 秒

## 安装依赖

### Playwright 安装

```bash
# 安装 Playwright Python 包
pip install playwright

# 安装 Chromium 浏览器
playwright install chromium
```

### 其他依赖（已包含）

```bash
pip install requests beautifulsoup4
```

## 使用方式

### 方式一：用户输入网址
1. 选择平台（如 TikTok）
2. 选择"二创"模式
3. 在输入框输入网址，例如：
   - `https://www.tiktok.com/@user/video/123`
   - `www.youtube.com/watch?v=abc123`
   - `example.com`

### 方式二：系统自动识别
用户输入的文本如果是网址格式，系统会自动识别并抓取。

## 支持的网址格式

| 格式 | 示例 | 说明 |
|------|------|------|
| `https://` | `https://example.com` | 标准 HTTPS |
| `http://` | `http://example.com` | 标准 HTTP |
| `www.` | `www.example.com` | 自动添加 https:// |
| 纯域名 | `example.com` | 自动添加 https://www. |

## 抓取流程

```
用户输入网址
    ↓
验证 URL 格式
    ↓
尝试 Playwright（优先）
    │
    ├─→ 启动 Chromium
    ├─→ 设置 User-Agent
    ├─→ 访问网址
    ├─→ 等待加载完成
    ├─→ 提取内容
    └─→ 返回文本
    │
    ↓ 失败
    ↓
尝试 Web-Reader MCP（预留）
    │
    ↓ 失败
    ↓
尝试 Requests + BeautifulSoup
    │
    ├─→ HTTP 请求
    ├─→ HTML 解析
    └─→ 提取内容
    │
    ↓ 返回结果
```

## 内容清理

自动处理的清理操作：
- 移除脚本、样式标签
- 移除导航、页脚、侧边栏
- 清理多余空白（3个以上换行）
- 清理多余空格（3个以上空格）
- 提取页面标题
- 限制最大长度（15,000 字符）

## 错误处理

| 错误类型 | 返回信息 |
|---------|---------|
| 无效网址格式 | `错误：无效的网址格式` |
| Playwright 未安装 | `错误：Playwright 未安装，请运行: pip install playwright` |
| 网络超时 | `错误：抓取过程异常 - timeout` |
| 无法连接 | `错误：Playwright 执行失败 - navigation failed` |
| 无内容可提取 | `错误：无法提取页面内容` |
